# Parametric Models

A collection of procedural, parametric 3D models created with Blender Python (`bpy` / `bmesh`) for personal 3D printing projects.

## Available Models

- `db9_hood.py`: Two-piece parametric hood enclosure for DB9 (D-Sub 9) solder connector.
- `tolino_vision_5_case.py`: Parametric protective bumper case for Tolino Vision 5 / Kobo Libra H2O e-reader.

## Usage

Run any script inside Blender's Scripting workspace or via command line:

```bash
blender --background --python <model_script>.py
```
